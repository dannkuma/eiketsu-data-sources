# Domain Guide

## Purpose

このドキュメントでは、
本プロジェクトで扱う「英傑大戦」のドメイン知識を説明します。

実装・調査・レビュー時に、
ゲーム仕様や用語の意味を判断する必要がある場合に参照してください。

## Game Overview

本プロジェクトが対象とする「英傑大戦」は、
1対1で対戦するアーケードカードゲームです。

プレイヤーは歴史上の人物をモチーフにした
「武将」を操作します。

複数の武将カードを組み合わせることで
「デッキ」を構築します。

## Core Domains

### 武将 / General

武将は本プロジェクトの中心となるドメインです。

コード上では主に以下の名称を使用します。

- `general`
- `generals`

`general` という名称が使用されている場合、
基本的には武将を意味します。

主なデータは `generals` テーブルと関連します。

### 戦器 / Heirloom

戦器は、試合中に使用できる特殊なアイテムです。

コード上では主に以下の名称を使用します。

- `heirloom`
- `heirlooms`

`heirloom` という名称が使用されている場合、
基本的には戦器を意味します。

主なデータは `heirlooms` テーブルと関連します。

### 英魂 / Soul

英魂は武将へ付与できる強化要素です。

コード上では主に以下の名称を使用します。

- `soul`
- `souls`

`soul` という名称が使用されている場合、
基本的には英魂を意味します。

### 大判 / Balance

大判は戦器・英魂などの取得に使用する
ゲーム内通貨です。

本プロジェクトではユーザーが所持する大判を、
主に `balance` という名称で扱います。

`balance` がゲーム内資産に関する文脈で使用されている場合は、
基本的に大判を意味します。

## Heirloom and Soul

戦器には英魂を装着できます。

1つの戦器に対して、
1つの英魂を装着できます。

英魂を利用することで、
対象となる武将のステータスへ効果を与える仕組みがあります。

戦器・英魂の購入や強化などでは、
大判を使用します。

## Main Features

### 武将一覧

登録されている武将カードを一覧表示します。

主な機能:

- 武将情報の確認
- 絞り込み
- ソート
- デッキ構築
- デッキ画像生成
- お気に入り登録

### 戦器一覧

登録されている戦器を一覧表示します。

主な機能:

- 戦器情報の確認
- 絞り込み
- ソート
- 大判を利用した購入

### 英魂一覧

登録されている英魂を一覧表示します。

主な機能:

- 英魂情報の確認
- 絞り込み
- 大判を利用した購入

### 所持戦器

ログインユーザーが所有する戦器を管理します。

主な機能:

- 詳細確認
- 強化
- 英魂の着脱
- 売却
- ロック
- 戦場持ち込み状態の変更

### 所持英魂

ログインユーザーが所有する英魂を管理します。

主な機能:

- 英魂の着脱
- 効果の再抽選
- 効果の固定
- 売却
- ロック

### Authentication

以下の認証関連機能があります。

- ログイン
- パスワード再設定
- ユーザー登録
- ユーザー情報変更

### Balance Purchase

ユーザーは決済サービスを通じて
大判を購入できます。

決済処理には Stripe / Laravel Cashier を使用します。

## Administration

管理者向けに以下の管理機能があります。

### ユーザー管理

ユーザー情報の確認・変更を行います。

### 武将管理

武将情報の登録・変更を行います。

また、以下をサポートします。

- CSV エクスポート
- CSV インポート

### 戦器管理

戦器情報の登録・変更を行います。

また、以下をサポートします。

- CSV エクスポート
- CSV インポート

### 英魂管理

英魂情報の登録・変更を行います。

また、以下をサポートします。

- CSV エクスポート
- CSV インポート

## Review Notes

ドメインロジックをレビューするときは、
名称だけから仕様を推測しないでください。

特に以下に関係する処理では、
関連する Model、Service、Migration、Test を確認してください。

- 大判の増減
- 戦器の購入
- 戦器の売却
- 英魂の購入
- 英魂の売却
- 英魂の着脱
- 強化処理
- ロック状態
- 所有権
